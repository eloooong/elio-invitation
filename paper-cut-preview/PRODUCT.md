# Elio’s first birthday invitation

A mobile-first invitation for Elio Rayne’s first birthday, December 22, 2026, 3–6 PM Manila time, at Kidzoona, SM City Laoag.

Family and friends can read party details, browse the monthly photo journal, open the venue map, and RSVP. Hosts can review and edit replies and invitation content.

This directory provides an isolated local preview and the approved design used by the production build. The user authorized deployment to https://elios-birthday.vercel.app. Future deployments still require an explicit user request. Preview replies and edits use separate browser-local storage keys with the backend disconnected; production builds restore shared API mode and preserve the existing database.

The user chose layered cut-paper illustration based on their supplied reference, adapted to the website’s forest green, cream, sage and gold. Keep Elio’s supplied photograph authentic. Never invent photos for empty months. Friendly complete animal silhouettes and grounded walking motion are requirements.

Preserve the existing invitation content and interactions. Support small phone screens, keyboard navigation, visible focus and reduced motion. Bundle artwork, fonts, audio and supplied photos in the downloadable HTML; Google Maps and calendar links remain external services.
